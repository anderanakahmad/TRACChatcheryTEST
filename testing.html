Use the TRACC test repository to evaluate the interface on an actual phone. This is a simulated system: there are no staff accounts, no cloud database, and no shared approval queue.

Important: A downloaded request file is how you can test warden → administrator handoff on different devices without a database. Approval affects only the importing browser. No publication reaches other people's devices.

Staff feedback

Check the issues and save feedback as a text file to share with the project owner. No feedback is sent to a server.

What this demo cannot prove

It cannot test secure authentication, database roles, synchronization between two phones, push notifications or reliable offline syncing. Those need a later sandbox database and real login accounts. QR codes open public nest views only, not protected data.
