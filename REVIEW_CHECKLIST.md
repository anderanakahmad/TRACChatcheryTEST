# Administrator publication checklist

Before approving a new nest or edit, the TRACC administrator should verify:

- [ ] The record has a unique portal nest ID and a verified relocation date.
- [ ] The recorded **nesting season matches the relocation date's calendar year**.
- [ ] Egg count and taxon/species match the source field sheet; inconsistencies have been resolved or noted privately.
- [ ] When release outcomes are entered, healthy and deformed hatchling counts are both provided, including a numeric **0** where none were observed. The public release count is their sum.
- [ ] No release count was invented from hatching/emergence success, or vice versa.
- [ ] Predicted emergence dates are clearly estimates; actual dates and final status reflect observed events.
- [ ] Island sector is generalized and suitable for public display. No GPS, exact nesting position, poaching-sensitive directions or precise private locations are exposed in any public field or metadata.
- [ ] Mother data is published **only** if a real left or right tag number exists, the staff member opted to share, and TRACC has authorized public tag/measurement disclosure.
- [ ] Public warden name and visitor update are appropriate to share.
- [ ] Each custom metadata field has a correct **Public after approval** or **Staff only** visibility; public values are screened for confidential research information.
- [ ] The proposed new/changed record is not a duplicate of a previously approved record; revised records refer to the correct prior version.
- [ ] The proposal is approved/rejected using the administrator review function; wardens cannot publish directly.

Check the public preview after approval. Verify that any deleted metadata fields have disappeared from public details and that the season/species charts and totals update correctly. Keep the source datasheet private and backed up.
